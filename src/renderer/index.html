Hosts 一键加速

用检测结果里的实际建连 IP 写入 hosts，绕过被污染的解析。写入前自动备份，可一键还原。

Git 代理配置

为 git 写代理配置（~/.gitconfig），可选仅对 GitHub 生效，并可把 git:// 协议改写为 https://。

URL 镜像改写加速
